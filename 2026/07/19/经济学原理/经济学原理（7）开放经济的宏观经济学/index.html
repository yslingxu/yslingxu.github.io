经济学原理（7）开放经济的宏观经济学

发表于2026-07-19|更新于2026-08-20|经济学原理
|浏览量:

1. 开放经济的基本概念

1.1. 物品和服务的流动

  • 进出口：国家对外购买或者销售物品及服务
  • 净出口：出口 - 进口
  • 贸易盈余（顺差）：净出口 > 0
  • 贸易赤字（逆差）：净出口 < 0

1.2. 金融资源的流动

  • 资本净流出：本国人购买外国资产 - 外国人购买本国资产，这种资产可以是直接投资或者有价证券
  • 资本净流出 = 净出口

1.3. 储蓄和投资

根据GDP公式的变形，储蓄 = 国内投资 + 资本净流出

1.4. 美国的贸易赤字

  • 不平衡的财政政策【政府预算赤字的增加（如减税、国防支出增加等）导致】：在储蓄减少作为既定事实时，外部投资可以刺激经济
  • 投资高涨【科技发展等导致的外部投资高涨】：如果投资带来了好的收益，则对整体经济有好处
  • 经济衰退【经济衰退导致投资降低，政府为了刺激经济而扩大预算赤字】

总体来说，贸易赤字并不算一个问题，但是贸易赤字有时候会是其他经济问题的征兆。

2. 汇率

2.1. 真实汇率与名义汇率

  • 名义汇率：银行提供的汇兑服务的汇率
  • 真实汇率：双方市场同一物品的价格比值

2.2. 汇率决定理论

购买力平价理论：汇率由两国的物价水平比率决定，该理论的基础是价差会导致套利空间，但是受到贸易管制、贸易成本和消费者偏好等影响，该理论并非完美，但是总体框架和方向上是没错的。

2.3. 贸易协定

贸易协定不会对开放经济造成巨大冲击，但是会导致部分赢家和部分输家。

3. 开放经济的宏观经济理论

3.1. 可贷资金市场与外汇市场

  • 可贷资金市场：可贷资金（可用于资本积累的资金）的供给来自储蓄，需求来自国内投资 + 资本净流出，其供需关系与存贷利率相关联。
  • 外汇市场：货币供给来自资本净流出，货币需求来自净出口，货币供需关系和真实汇率相关联。

以上两个市场通过资本净流出关联。

3.2. 供需的界定

同一笔交易，有些时候既可以界定为供给，也可以界定为需求。比如农场主消费了自己农场生产的苹果，既可以界定为苹果供给的减少，也可以界定为苹果需求的增加。

3.3. 政策影响

  • 政府赤字：政府赤字会降低储蓄，推高利率，降低资本净流出，导致货币升值
  • 贸易限制：增加净出口，导致货币升值，进而抵消贸易限制带来的优势，压制净出口。最终，总体的贸易余额实际上并不受到影响
  • 国家评级降低：政治不稳定等情况导致的国家评级降低会导致资本外逃，即资本净流出升高，货币贬值，利率升高。而对于接收外逃资本的国家来说，则货币升值，利率降低

3.4. 开放经济的影响力

对于一个大国来说，开放经济对国内经济的影响力相对有限，内生影响占比会更大。

4. 短期经济波动

  • 经济波动是无规律且不可预测的
  • 大多数宏观经济变量同时波动，但是幅度和方向有差异
  • 产量的减少会导致失业增加

古典经济理论认为，货币是中性的，其变动不会影响真实变量，仅仅影响名义变量。这个说法在长期经济中成立，但是在短期经济中并不成立。

4.1. 总需求曲线

物价水平下降等一些事件，会导致消费者购买力增强、政府购买增加、利率下降和通货贬值，并分别刺激消费品、投资品和净出口需求，导致总需求增加。

4.2. 总供给曲线

总供给只受到生产力水平的影响，所以长期中总供给曲线是垂直的，只有劳动、资本、自然资源和技术等因素会导致总供给曲线变动。

长期来看，随着生产力水平的发展，总供给会持续增加，而随着央行对货币的增发，总需求也会增加，进而导致长期的物价上升，即通货膨胀。

基于工资、物价的粘性和错觉理论（生产者观察到其他物品的物价变动，进而错误地判断自身生产的产品的物价变动），在短期中，物价水平上升会导致总供给上升。

除了劳动、资本、自然资源和技术等因素，人民预期物价水平也会影响短期总供给，当人民预期物价水平上升时，会抑制供给。

4.3. 经济波动的两个原因

一些意外事件如政府的错误政策、股市楼市泡沫、战争等导致的总需求或者总供给变动，进而导致经济波动。

  • 总需求变动短期内引起产量波动，长期内影响物价总水平，但是不影响产量
  • 总供给降低会导致滞胀（产量下降、物价上升、失业增加），物价上升进一步催高名义工资，进而导致企业成本增加，供给进一步降低，形成恶性循环，但是发展到一定程度之后，失业率增加，会导致名义工资开始降低，进而开始回落
  • 通过一些政策可以影响上述波动的幅度和持续时间，但是这些政策也可能会带来一些负面影响如通货膨胀等

5. 货币和财政政策对总需求的影响

5.1. 货币

流动性偏好理论：货币供给由央行/美联储控制（央行/美联储不会设定一个具体的货币供给量，而是会设定一个联邦基金利率目标，并通过增减货币的操作达到这个目标，由此可见，货币供给与利率息息相关），货币需求则会跟随利率的影响达到均衡。

长期利率主要受可贷资金市场影响，短期利率主要受流动性偏好即货币供需影响。

货币供给增加时，利率降低，总需求增加。

股市作为经济中的重要一环，与经济息息相关，所以美联储和股市之间会互相关注和影响。

当利率无限接近0时，再想通过降低利率的方式来刺激经济就无效了。但是，央行可以通过量化宽松或者推高通货膨胀率（会导致真实利率降低到负数）来刺激经济。

5.2. 财政政策

  • 政府购买：政府购买增加会导致总需求增加，变动幅度由以下两个效应的具体情况决定
    • 乘数效应：政府购买增加X，政府的直接供应商需求增加X，但是直接供应商还会有下级供应商，所以需求会向下传递，形成乘数效应，最终变动幅度为X * (1 - Y)，这里Y等于供应商的边际消费倾向（消费占总收入的比例）
    • 挤出效应：政府购买增加X，社会财富增加，货币需求增加，利率上升，反过来抑制需求，甚至可能导致最终变动幅度小于X
  • 税收变动：减税增加消费支出，推高总需求。变动幅度受乘数效应和挤出效应影响，另外，还会受到家庭对税收变动持续性预期的影响，如果预期很短，则幅度有限

财政政策也会影响总供给，如减税导致工人工作热情增加，政府购买公路导致社会运转效率增加等。

5.3. 用政策来稳定经济

关于政府和央行是否应该积极地运用政策来稳定经济：

  • 支持者认为稳定经济是政府和央行的责任，且政策手段行之有效，所以应积极干预
  • 反对者认为经济变动不可准确预测，政策手段经常滞后，所以不应积极干预，应该温和干预
  • 支持者和反对者都支持自动稳定的调控机制如阶梯性比例税制、失业保险等，这些自动稳定的调控机制不需要人工干预，所以不会有迟滞性，但是相对应的，这些调控机制作用相对有限，无法完全阻止衰退

6. 通货膨胀与失业之间的短期权衡取舍

  • 长期：通胀由货币增长引起，但是货币增长并不会引起失业。两者并无关联
  • 短期：总需求增加会导致通胀和减少失业，总需求减少会压制通胀并增加失业。两者面临取舍

对于滞胀带来的高通货膨胀和高失业结合，如果努力阻止产量下降以增加总需求，会缓解滞胀，但是收效甚微。如果通过紧缩政策压制通胀，会导致产量下降，但是这能够压制人民的通胀预期，滞胀会得到极大缓解，产量下降的实际幅度会比数学预期要小很多。

7. 宏观经济政策的六个争论问题

7.1. 决策者应该试图稳定经济吗

  • 经济波动会产生无谓损失，所以决策者应该运用政策来稳定经济
  • 政策对经济的影响存在滞后性，往往在半年以上，所以有的时候政策反而会起到反效果。经济会自行恢复，所以不应干预

7.2. 政府反衰退应该增加支出还是减税

  • 增加政府支出的提振经济效果远大于减税
  • 增加政府支出会加大债务，增加未来税收，这种可预期的情况会令消费者减少现在的支出。另外，增加政府支出可能会导致腐败和资金浪费（快速决策导致决策失误，购买到无价值物品或者服务）

7.3. 货币政策应该按规则制定还是灵活变动

  • 按规则制定可以避免权力滥用，提高公众可信度以压制通货膨胀（如果是灵活变动，公众不可信导致其预期通货膨胀会高于政策）
  • 灵活变动可以更好地处理各种未预见的情况，权力滥用、公众可信度的问题并不突出且可以通过其他方法解决，且难以制定一个完美的规则
  • 从实际来看，多国央行会结合两种方案，既制定规则，又在规则中保留一定的灵活变动范围，如将通货膨胀率规定在1%-3%之间

7.4. 央行应该把零通胀作为目标吗

  • 通货膨胀会带来皮鞋成本等多种成本
  • 不应该把零通胀作为目标
    • 压低通胀会短期带来失业等问题，而且如果公众不相信央行和政府能够一直压制通胀的话，甚至会带来长期问题
    • 轻微的通胀（2%左右）会刺激经济活力，提升生产力
    • 可以通过其他方法如指数化税制等来降低通胀的成本
    • 名义工资不容易下降，轻微的通胀使得真实工资更容易随着劳动市场的变动而变动
    • 大于零的通胀使得真实利率可以降到负数以刺激经济，通胀越高，刺激效果越好

7.5. 政府应该平衡其预算吗

  • 预算赤字会导致高债务，国民储蓄降低、利率升高、投资减少、资本存量减少、生产力降低
    • 战争导致的预算赤字可以理解，因为战争花费巨大，且不能通过无限加税的方式来筹资
    • 经济衰退时期的预算赤字可以理解，因为经济衰退时期需要通过政府支出来扩大总需求
  • 政府预算有很多会以教育、福利的形式返还公众。父母的储蓄可以随着遗产减轻子女未来的债务负担。而且只要债务增长的速度小于通货膨胀和生产力增长的叠加，债务其实可以一直循环持续下去，所以也无需维持零赤字

7.6. 应该为了鼓励储蓄而修改税法吗

  • 如果税法鼓励储蓄，那么储蓄就会增加，进而降低利率，增加投资，扩大生产力。通过所得税改消费税等方式可以鼓励储蓄。
  • 不应该修改税法来鼓励储蓄
    • 税法鼓励储蓄会加剧贫富分化
    • 当税法提高了储蓄的收益时，公众可能会因为收入增加，降低储蓄的必要性，进而抑制储蓄，所以税法对储蓄的影响不一定能够达到预期
    • 可以通过减少政府预算赤字和对富人加税的方式来增加总体储蓄并推进生产力发展
    • 储蓄激励政策可能会导致政府收入减少，导致预算赤字。如果政策导致的私人储蓄增加不能抵消政府收入的减少，则该政策反而会导致总体储蓄降低

1. 供给与需求市场是存在竞争的，而在一般情况下，供给与需求和价格存在强相关（即价格上升，供给增加、需求减少；价格下降，供给减少、需求增加），在市场的自然调节下，价格会自然变动，并最后收敛到一个供给等于需求的平衡点。当意外事件使得供需发生变化后，价格会再次自然变动，并再次收敛。 在这里，价格就充当了供给和需求调节的作用，即进行了稀缺资源的分配。 2. 为什么说市场往往是经济调节的一个好工具？ 消费者剩余（消费者的资金减去花费）可以衡量消费者在市场中得到的总利益，当价格下降时，消费者剩余增加 生产者剩余（销售金额减去总生产成本）可以衡量生产者在市场中得到的总利益，当价格上升时，生产者剩余增加 上述两者相加，可以得到市场总剩余（用于衡量市场总利益）。研究发现，当供需平衡时，市场总利益最大。所以市场往往是经济调节的一个好工具。 但是，由于存在市场非完全竞争（如垄断等）和外部性（如工厂生产产生污染影响农民等）等情况，市场有的时候也会失灵。 3. 弹性 需求价格弹性：衡量物品价格变动对需求的影响幅度。如果影响很大，则称为富有弹性；如果影响较小，则称为缺乏弹性。一般来说，生活必需品和无替代...
